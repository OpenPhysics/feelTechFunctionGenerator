FeelTech FY3200S

Drive the function generator from your browser over Web Serial.

Not connected
This browser cannot talk to the instrument. The Web Serial API is required, and is available in desktop Chrome and Edge (and Chromium derivatives). Firefox and Safari do not implement it, and neither do browsers on iOS. You can still explore the controls and the preview below — nothing will be sent to any hardware.
Web Serial needs a secure page. Open this page over https:// or on localhost.

Waveform preview

Computed from the settings you have sent — this is not a measurement of the output. Use a real oscilloscope to see what the instrument is actually producing.

Serial console

Every byte exchanged with the instrument. Commands are plain ASCII at 9600 baud: bf100000 sets channel 1 to 1 kHz.

The FY3200S appears as a CH340 USB-serial bridge, so this page uses the Web Serial API rather than WebUSB — no driver changes needed. Settings are remembered in this browser only.
